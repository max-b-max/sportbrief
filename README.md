# SPORTBRIEF

Projet personnel de pipeline de données sportives.

Objectif : agréger, filtrer et synthétiser les actualités sportives pour réduire le temps d'écran.

## Idée

En tant que passionné de sport, je consulte trop de sources différentes chaque jour.
Ce projet vise à créer un pipeline automatisé qui :
1. Collecte les actualités via RSS et APIs
2. Filtre selon mes préférences
3. Génère un résumé audio quotidien

## Stack prévu
- Python
- feedparser pour les flux RSS
- APIs sportives (à explorer)
